# Naukri Job Watcher

Independent 24x7 Naukri job watcher for Windows.

## Scope
- Search Naukri using configurable keywords and locations.
- Prefer jobs posted within the last 24 hours.
- Paginate available search results.
- Deduplicate jobs in SQLite.
- Extract full job details.
- Score jobs using configurable keyword rules.
- Optional OpenRouter AI analysis with keyword-only fallback.
- Send new matching jobs to Telegram.
- Never auto-apply.
- Run continuously through Windows Task Scheduler.

## Important
This repository is completely separate from `Naukri_refresh`.
Do not copy its code, browser profile, database, or scheduled task into this project.

Credentials and browser state stay local and are excluded from Git.
